# Security policy

## Supported versions

Only the latest release of doot gets fixes.

## Reporting a vulnerability

Please **don't open a public issue**. Report it privately through
[GitHub's security advisories](https://github.com/Theyashsawarkar/doot/security/advisories/new),
with what an attacker could do and how to reproduce it. You'll get a reply
within a week; a fix and a release follow as soon as it's confirmed, with
credit to you unless you'd rather not.

doot runs as your user and runs only the commands it documents (and the
ones you configure in `~/.config/vyom/config.toml`).
