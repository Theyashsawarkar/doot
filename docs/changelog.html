Changelog

Every change to doot, newest first. Releases are git tags (all tags, GitHub releases); the source of this page is CHANGELOG.md.

Unreleased

  • Website: pranali joins the family list in the footer; the site builder passes ruff.
  • New screenshots in the Spatial look, taken with made-up demo data (WebP, sharp on high-density screens).
  • The website, closer to Vayu's own: the tool's screenshot blurred behind the page, a centred hero with the logo and the verse, the page you're on as the white pill, glass "On this page" and footer panels, releases as cards. No glow behind the logo, no coloured line beside the verse.

v0.3.02026-11-09Release notes

  • Vim keys (Vyom 0.7): doot opens in NORMAL mode, where letters are keys and typing changes nothing; / (or i) types to search the phone's actions, Esc goes back. Space is the leader, with a which-key strip; ? lists every key and Space Space is a palette of every action. Digits aren't counts here: 1..5 still run the actions.
  • New keys: Space x c / x f send the clipboard / a file, Space n r / n p ring / ping the phone, Space o f opens its storage, Space a a / d r accept / reject a pairing request, Space y b copies the battery level. In the file list l sends and h or q go back.
  • Unpair asks with one question: Space d d (or the Unpair button) asks "Unpair …?", y unpairs and any other key keeps it. Ctrl+U no longer unpairs: it scrolls half a page up, as in every vim tool.
  • Keys are data (doot/vim.py); scripts/keybinds.py writes the # keybind: lines and the README table from it (--check in CI).
  • Needs Vyom 0.7.0.

v0.2.02026-11-07Release notes

  • A new look (Vyom 0.6): the phone at the top, its battery as a ring, "Connected" in green, signal bars with a word, the network and charging.
  • Actions as numbered tiles (send clipboard, send a file, ring, browse, ping): with the search box empty, 1..5 runs one; typing still searches them.
  • Unpair is red, apart, and asks first: Ctrl+U (or its button) once shows a red note, a second time within 5 seconds unpairs. It used to unpair at once.
  • Other devices say "Enter pairs"; the preview pane is gone (everything it showed is at the top now).
  • No transfer list: KDE Connect doesn't publish its transfers' progress.
  • Needs Vyom 0.6.0.
  • Every corner is rounded: the website's callouts.
  • A logo and a shloka at the top of the README and the website: every Vayu tool has them now.
  • Screenshots in the README and on the website.

v0.1.32026-10-21Release notes

  • A website (GitHub Pages, https://theyashsawarkar.github.io/doot/): the README as a home page, the changelog, and architecture decision records (docs/adr/), built from these files by scripts/build-site.py; CI checks the site is up to date.

v0.1.22026-10-21Release notes

  • Documentation for open source: a logo and banner, a full README (features, install, usage, configuration, troubleshooting, the whole Vyom family), CONTRIBUTING, SECURITY and CODE_OF_CONDUCT, issue and pull request templates, and CI (compiles, checks plugin.toml and that every key is documented).

v0.1.12026-10-19Release notes

  • Keys are spelled out (Ctrl+Enter, Shift+Enter, Backspace) instead of symbols (⌃↵, ⇧↵, ⌫) in the footer and on rows and buttons.

v0.1.02026-10-19Release notes

  • First release, as its own repository: your phone, through KDE Connect. Replaces phone-picker.py in Vayu.
  • The phone's battery, charging and mobile signal at a glance.
  • Its actions as rows: send the clipboard, send a recent file (from Downloads, Pictures, Documents…), ring it to find it, ping it, browse its storage, unpair.
  • Pairing requests at the top with Accept / Reject and the verification key; other known devices below (pair the reachable ones).
