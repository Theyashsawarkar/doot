Changelog

Every change to doot, newest first. Releases are git tags (all tags, GitHub releases); the source of this page is CHANGELOG.md.

v0.1.32026-10-21release ↗

  • A website (GitHub Pages, https://theyashsawarkar.github.io/doot/): the README as a home page, the changelog, and architecture decision records (docs/adr/), built from these files by scripts/build-site.py; CI checks the site is up to date.

v0.1.22026-10-21release ↗

  • Documentation for open source: a logo and banner, a full README (features, install, usage, configuration, troubleshooting, the whole Vyom family), CONTRIBUTING, SECURITY and CODE_OF_CONDUCT, issue and pull request templates, and CI (compiles, checks plugin.toml and that every key is documented).

v0.1.12026-10-19release ↗

  • Keys are spelled out (Ctrl+Enter, Shift+Enter, Backspace) instead of symbols (⌃↵, ⇧↵, ⌫) in the footer and on rows and buttons.

v0.1.02026-10-19release ↗

  • First release, as its own repository: your phone, through KDE Connect. Replaces phone-picker.py in Vayu.
  • The phone's battery, charging and mobile signal at a glance.
  • Its actions as rows: send the clipboard, send a recent file (from Downloads, Pictures, Documents…), ring it to find it, ping it, browse its storage, unpair.
  • Pairing requests at the top with Accept / Reject and the verification key; other known devices below (pair the reachable ones).
